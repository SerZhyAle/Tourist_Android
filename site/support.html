Report a problem or ask a question

The public place is the issue tracker of the repository: https://github.com/SerZhyAle/Tourist_Android/issues. Anyone with a GitHub account can open an issue and follow the answer.

What a report should contain

  • What you pressed and what you expected to happen.
  • What happened instead, and whether it happens every time.
  • The model of your phone or watch and its Android or Wear OS version.
  • The Tourist version, shown in Settings.
  • Optionally the diagnostic ZIP described below.
The point

An issue is public. Leave out your coordinates and anything else private; use the address below for that.

Privately, or for a security problem

Write to sza@ukr.net. It is the one contact for everything that should not be public, a security problem included.

What to expect

Tourist is made and supported by one person. Reports are read and answered as time allows; there is no fixed response time.

Export diagnostics

Settings, Export diagnostics saves a ZIP with the app version, the Android API level and the memory limit. It holds no coordinates, history, music path or text you typed. Nothing is uploaded: you choose where the file is saved and whether to attach it to a report.

Privacy and source

What the apps read, store and send is in the privacy policy. The code is in the repository.
