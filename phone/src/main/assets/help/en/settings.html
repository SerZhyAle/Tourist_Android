Settings

Changes apply immediately and remain after you leave. Use Pages to switch between Main and About.

In this order

  1. Open Pages 1 to select a page.
  2. Choose theme 2, language 3 and units 4.
  3. Set Keep screen awake 5 for instrument screens.
  4. Open About 6 for resources and diagnostic export.

The elements

1PagesPage menu

Selects Main or About in the same window. On wide screens the menu stays visible.

2ThemeTheme

System default follows the device; Light and Dark select a fixed appearance.

3LanguageLanguage

Choose an endonym or follow the system. The application updates its language immediately.

4Measurement systemMeasurement system

Metric or imperial units apply to readings on the phone and paired watch.

5Keep screen awakeKeep screen awake

Enabled keeps instrument screens awake. Disabled uses the system timeout. Touch-lock behavior of the water flashlight is unchanged.

6About Shown only when neededAbout

Shows the running build, license, privacy, offline help and related products. Export diagnostics opens the system file destination picker and saves a ZIP containing build and platform values. It excludes coordinates, history, music paths and user text. Nothing is uploaded.

7Help (F1)Help

Opens this page. F1 on a connected keyboard does the same.
