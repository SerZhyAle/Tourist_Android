Stopwatch result

This window opens from the stopwatch screen when you press Result. Add a description and a note if you like, check the preview, then save the text to a file or share it; Cancel or Back returns to the stopwatch.

In this order

  1. Type a description 1 and, if you want, a note 2. Both are optional, and an empty field is left out of the text.
  2. Read the preview 3. It is the text that will be saved or shared, so correct the fields above until it reads as you want.
  3. Press 4 to write the text into a file in your Downloads folder, or 5 to hand it to another app through the system share sheet.
  4. Press Cancel, Back or Esc to close the window without saving or sharing; the stopwatch stays as it was.

The elements

1DescriptionA title line for the result (optional).

A line placed at the top of the text, for example the name of the run. It is left out when empty.

Why
It tells whoever reads the text what was measured.
Next
The preview shows it at once.
Undo
Yes, edit or clear it; nothing leaves the window until you save or share.
Tip

What you have typed stays if you rotate the phone.

2NoteAn extra remark (optional).

A second line below the description, for example a remark about the run. It is left out when empty.

Why
Use it for anything the times do not say by themselves.
Next
The preview shows it at once.
Undo
Yes, edit or clear it; nothing leaves the window until you save or share.
3PreviewThe exact text that will be saved or shared.

Shows the description and the note, a line with the date and time of the measurement, then one line per participant with the total time and the lap times in the order they were recorded.

Why
Read it before you save or share: what you see here is what leaves the window.
Next
It follows what you type in the two fields above. The times are those of the moment you opened this window, even if the stopwatch is still counting behind it.
Tip

You can select text in the preview and copy it.

4Save to fileSaves the text as a file in Downloads.

Writes the preview as a plain text file into your Downloads folder; its name starts with Tourist_stopwatch and carries the date and time.

Why
Use it to keep a record of the run on the phone.
Next
The window closes and a short message names the saved file, or says that it could not be saved.
Undo
Saving again makes another file. A file you no longer want stays in Downloads until you delete it there.
Shortcut
Enter on a connected keyboard saves, unless a button in the window has the focus.
5ShareHands the text to another app.

Opens the system share sheet with the preview as text; there you choose which app receives it. The text goes on only when you pick an app.

Why
Use it to pass the times on at once, without saving a file.
Next
The window closes and the share sheet opens; from there the text is in the hands of the app you choose.
Undo
Closing the share sheet without a choice sends nothing; text already sent from another app cannot be recalled from here.
6Help (F1)Opens this page.

The question mark in the title of the window opens this page.

Why
It explains the window with a picture, without leaving the app and without a network.
Next
Back closes help and returns to this window.
Shortcut
F1 on a connected keyboard does the same.
