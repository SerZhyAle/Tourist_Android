Counter

The counter tallies anything you count by hand on the way. Each count is one tap on +1; the number is kept when you leave the screen or close the app. Open it from the dashboard: tap the Counter tile, then tap the big card.

In this order

  1. Read the count 1: the large number is the current count, with the starting number under it.
  2. If the count should not begin at 0, press Starting number 5 first: the number you enter becomes the count at once.
  3. Tap the +1 button 2 for each item you count, and the -1 button 3 to correct a miscount.
  4. For larger steps switch on More buttons: +3 to +1000 4 and use the extra buttons.
  5. When one count is finished, press Reset 6 and confirm: the result goes to the history and the count returns to the starting number.
  6. Look up earlier results in History 7; the Clear button there empties the list after you confirm.
  7. Press 8 to read this page again.

The elements

1The countThe current count, in large figures.

Shows the number you have counted, with the starting number under it and, once you have counted something since the last reset, the time that count began.

Why
It is the one number to read: the dashboard's Counter tile shows the same count.
Next
It changes at once with every button, and each change is saved.
Undo
It never goes below 0 and stops at 999999999; -1 takes one back and Reset returns it to the starting number.
2Add oneAdds one to the count.

The large button on the right. Each tap adds 1 to the count at once.

Why
Use it for every item you count.
Next
The number updates and is saved; the first tap after a reset also records when this count began.
Undo
Tap -1 to take one back.
Tip

With a keyboard or a D-pad the screen opens with this button focused, so Enter adds one.

3Subtract oneTakes one off the count.

The smaller button on the left. Each tap subtracts 1; at 0 it is dimmed and does nothing, because the count never goes below zero.

Why
Use it to correct a miscount or to take back an extra tap.
Next
The number updates and is saved at once.
Undo
Tap +1 to put it back.
4More buttons: +3 to +1000Shows buttons for larger steps.

A switch that shows or hides six more buttons - +3, +5, +10, +50, +100 and +1000 - each adding that many at once. They only add; there are no larger subtract buttons.

Why
Use them when you count in groups or the number is large.
Next
The checkbox is remembered, so the buttons are still there the next time you open the counter.
Undo
Switching it off hides the buttons and changes no number.
5Starting numberSets the number the count begins from.

Opens a small window with one field for a whole number from 0, nine digits at most; OK accepts it and Cancel closes the window without changes. The number becomes the starting number and the current count at once, and the count it replaces is not saved in the history.

Why
Use it when the count should not begin at 0, for example to carry on from a number you noted earlier.
Next
The large number jumps to it, and Reset will return to it later. An empty field keeps the window open with the message Enter a whole number from 0.
Undo
There is no undo, and the replaced count does not go to the history.
Tip

The window has its own help button, and F1 in it opens this entry too.

6ResetEnds this count and starts the next.

Asks you to confirm, naming the starting number; on Reset it saves the current count in the history with its start and end time and returns the number to the starting number. Cancel leaves everything as it was.

Why
Use it when one count is done and a new one begins, and you want to keep the result.
Next
The large number shows the starting number again, and the finished count is at the top of the history.
Undo
The reset cannot be undone, but the finished count stays in the history.
Tip

A reset when nothing has been counted since the last reset, or since the starting number was set, adds nothing to the history.

7HistoryFinished counts, newest first.

Lists each count you ended with Reset: the number it reached and the period it ran; until there is one, the list reads No finished counts yet.

Why
Use it to look up how earlier counts ended.
Next
Clear asks Clear the counter history? and, when you confirm, removes every row; it is dimmed while the list is empty.
Undo
Clearing cannot be undone, and it does not change the current count.
Tip

The history keeps the latest 100 counts; older ones drop off the end of the list.

8Help (F1)Opens this page.

The help button in the top-right corner of the top bar opens this page without leaving the app.

Why
It explains the counter with a picture, without a network.
Undo
Opening it changes nothing; Back closes it.
Shortcut
F1 on a connected keyboard does the same.
