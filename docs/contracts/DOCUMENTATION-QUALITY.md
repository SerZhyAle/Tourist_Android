What this repository owes:

- `DOC-INTERNAL-QUALITY` binds this repository as a product maintaining developer documentation:
  `AGENTS.md`, `CLAUDE.md`, `README.md`, `docs/`, `PLAN/` and the Markdown files under `tools/`. Since S0029
  rules 1-3, 5 and 6 are held by `tools/docs/check-docs.ps1` (run by `tools/fast-check.ps1 -Area docs`; how it
  works is in `tools/docs/README.md`), the check that 0.11 item L asks the adoption row to name:
  - Rule 1: two registries in the reference record shape - `docs/DOCUMENT_REGISTRY.jsonl` for everything outside
    `PLAN/`, named in `.sza-canon.json` (item J), and `PLAN/DOCUMENT_REGISTRY.jsonl` beside the folder it indexes
    (placed as item K names). `generated` is the role: `true` render, `false` source. The harness
    `document_registry/validate` also judges the one the stamp names.
  - Rule 2: registry to disk and disk to registry, with an explicit ignore list (empty today); a tracked
    registry names no git-ignored file and a local one only ignored files (item K).
  - Rule 3: relative links and `#fragment` anchors resolve. `PLAN/DONE/` is a declared frozen archive (item Q):
    links inside it are not judged, links into it are, and its files stay registered.
  - Rule 5: no three dots, ellipsis character, em or en dash in Markdown prose. Diacritics and code comments
    are not checked mechanically.
  - Rule 6: image links, image paths in code and numbered screenshot bookmarks resolve; a tracked document
    cites no git-ignored asset.
  - Accepted debt is a set baseline that may only fall, `tools/docs/baseline.txt`: four owner quotations in
    tickets that carry three dots.
- Rule 4 holds for the one generated family this product ships: the help pages and screenshots are
  regenerated by `tools/help/` and gated by `tools/help/check-help.ps1`, which fails a capture older than the
  layouts, strings or locale set it shows. Rule 7 holds in fact: the corpus reads offline and external links
  name stable anchors; no gate checks it.
- `DOC-EXTERNAL-QUALITY` is not applicable today: the product publishes no external documentation corpus
  and runs no site (the site is owner decision 4.9 of S0010, not taken). It becomes applicable the day that
  decision opens one; nothing is claimed for it in the registry.
- The in-app help prose in `docs/help/src/` is shipped product content governed by `CONTEXT-HELP` rule 13
  (the user's language, one source), not by this domain; its locales, gate and baseline are the help
  pointer's business. The registry lists those files; the help gate judges them.
